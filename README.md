## 📂 1. Main Bot Commands
> *Core administrative and user commands for the main bot instance.*

```bash
/start         - Launch and initialize the main bot
/help          - Open the interactive help dashboard
/settings      - Configure bot preferences and toggles
/clone         - Submit a BotFather token to create your own clone bot
/broadcast     - Broadcast a message to all main bot users (Admin Only)
/gbroadcast    - Broadcast a message to all main bot groups/chats (Admin Only)
